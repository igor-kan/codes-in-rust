# Scientific Rust Algorithms

High-performance, memory-safe numerical algorithms, automatic differentiation, Fast Fourier Transforms, and graph analytics in pure idiomatic Rust.

## Core Algorithm Suite

Beyond the scientific crate, the repository provides standalone Rust
implementations under `numerical/`, `data_structures/`, `strings/`,
`techniques/`, `cryptography/`, `geometry/`, `randomized/`, `searching/`,
`selection/`, and `greedy/`. Binary modules run their own assertions;
library modules compile with `rustc --crate-type lib`.
