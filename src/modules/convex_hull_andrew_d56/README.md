# Andrew Monotone Chain 2D Convex Hull (`convex_hull_andrew_d56`)

> Category: **Computational Geometry** | Language: **Rust 2021**

## Overview

Constructs the counter-clockwise minimal convex polygon enclosing integer planar points via lexicographic sweep without floating-point trigonometry.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Every cross product along consecutive hull edges is strictly non-negative (counter-clockwise).
