# Manacher Total Palindromic Substring Counter (`manacher_oddeven_d57`)

> Category: **String Algorithms** | Language: **Rust 2021**

## Overview

Runs dual odd-center and even-center Manacher expansions over byte slices to count all non-empty palindromic substrings cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Identical character run a^N yields exact N*(N+1)/2 palindromic slices.
