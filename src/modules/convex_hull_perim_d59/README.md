# Monotone Chain Convex Hull Perimeter & Area Doubler (`convex_hull_perim_d59`)

> Category: **Computational Geometry** | Language: **Rust 2021**

## Overview

Builds 2D convex hull polygons via Andrew monotone chain sweeps and returns exact doubled integer polygon area cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Interior collinear/contained points never alter doubled Shoelace hull area.
