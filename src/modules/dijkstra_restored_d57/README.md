# Dijkstra BinaryHeap Path Cost & Parent Trace Builder (`dijkstra_restored_d57`)

> Category: **Graph Shortest Paths** | Language: **Rust 2021**

## Overview

Computes both optimal path weight and reconstructed vertex sequence between source and destination via BinaryHeap Reverse ordering.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O((V + E) log V)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Sum of consecutive edge weights along reconstructed path equals reported total distance.
