# Tarjan Recursive Stack Strongly Connected Components (`tarjan_scc_rs_d59`)

> Category: **Directed Graphs** | Language: **Rust 2021**

## Overview

Discovers exact strongly connected component equivalence counts and vertex component assignments cleanly over directed adjacency lists.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Directed triangles produce 1 component while DAG chains yield N distinct components.
