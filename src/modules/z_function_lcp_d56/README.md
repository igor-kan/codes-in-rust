# Gusfield Z-Algorithm Linear Pattern Matcher (`z_function_lcp_d56`)

> Category: **String Matching** | Language: **Rust 2021**

## Overview

Computes exact prefix-match Z-array lengths [l, r] using linear Z-box window reuse and extracts all zero-based substring match offsets.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Every reported offset reproduces pattern byte-for-byte in the host text slice.
